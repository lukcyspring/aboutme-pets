# 桌宠动作包 + 一起做动作 + 碎碎念配图 · 拷贝包

打好包日期：2026-11-13（在 2026-11-12 那版基础上加了碎碎念配图）
来源机器：Lucky 的 Windows（DSH 桌面版，dsh-pet 插件）

这个包里是三只已经转好码的角色（直接从 `aboutme-pets` 的精灵图转成插件认的透明 webm），
每个角色还带了 27 张按它自己形象做的碎碎念配图，外加一个能让所有桌宠同时做同一个动作的小工具。
**拷过去不用再转一次、不用调接口、也不依赖 node。**

## 二、装之前确认两件事

1. **Windows 10 / 11**，有 PowerShell（系统自带，不用装）。
2. **目标机器已经装了 DSH 桌面版，并且装了 dsh-pet 插件、宠物在屏幕上跑着。**
   这个包**不含插件本体**，只含素材和配置。

不需要装 node，也不需要 ffmpeg —— 转换和出图都在打包前做完了。

## 三、装（推荐：双击）

双击 **`安装.cmd`**：

1. 它会打印要装到哪、每只多少段动作、多少张配图、多少 MB；
2. 问一句 `现在装进去？[y/N]`，输 `y`；
3. 等它把文件复制完（约 496 MB，机械硬盘上两三分钟）；
4. 回 DSH 的宠物设置页看「种类」里是不是多了 **猫耳娘 / GPT 动作包 / Claude 动作包**。
   插件每次启动读配置，一般不用重启；没出现就重启一次 DSH。

默认装到：

```
%USERPROFILE%\.dsh\dsh-pet\pet\
```

如果你改过 `DSH_HOME` 环境变量，脚本会自动跟着走到 `%DSH_HOME%\dsh-pet\pet`。
还想装到别处：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1 -Target "D:\某个目录"
```

### 手动装（不想跑脚本时）

把 `pet-packs\gemini\` 里四样东西复制进 `<pet 目录>\`，其余两只同理：

```
pet\
├─ gemini-config.json
├─ gemini-avatar.webp
├─ gemini-animation\     ← 100 个 .webm，平铺，不要再套子目录
├─ gemini-memes\         ← 27 个 .png，平铺，文件名就是梗名
├─ gpt-config.json
├─ gpt-avatar.webp
├─ gpt-animation\
├─ gpt-memes\
├─ claude-config.json
├─ claude-avatar.webp
├─ claude-animation\
└─ claude-memes\
```

命名必须**同前缀对齐**：`<名字>-config.json`、`<名字>-animation\`、`<名字>-avatar.webp`、`<名字>-memes\`，
四个前缀写成一样才会被识别。

## 四、碎碎念配图

三只角色的碎碎念气泡图不再是原来的蓝毛小女仆，换成各自形象：

- **猫耳娘**：自称「本喵」，动作包同款猫耳少女；
- **小白龙**：自称「本龙」，「誓死践行开源精神」那句改成了「坚决贯彻闭源思想」；
- **大小姐**：自称「本小姐」，同样的梗按大小姐的口吻重写。

27 个梗名跟主宠物完全一致（`可爱`、`死掉了`、`就一碗`、`黎曼猜想没证明喵`……），
所以触发逻辑不用改，插件按 `<素材根>-memes\<梗名>.png` 自己去找。

> `可爱` 那一张原图本来没有文字，所以是纯立绘。
> 想看图对不对：进 `pet-packs\<名字>\<名字>-memes\`，一眼扫一遍文件名即内容。

**注意**：配图只在 `<名字>-memes\` 存在时生效。如果你只装了 config 没拷 memes 目录，
碎碎念会退回包内默认的那套蓝毛小女仆图。

## 五、一起做动作

装完以后，双击 `pet-sync\一起做动作.cmd`：

- 它会先自己找 DSH 的端口（DSH 每次启动端口都可能变，不用你填）；
- 打印一份编号列表（所有宠物都会的动作，本机是 49 个）；
- 输编号或动作名（比如 `45` 或 `舞狮头`）；
- 再问 `Loop it? [y/N]`，输 `y` 就是循环；接着问隔几秒一轮（默认 10 秒，正好一段动作的长度）；
- 按 `Ctrl+C` 立刻停。

命令行直给也行：

```bat
一起做动作.cmd 舞狮头
一起做动作.cmd 舞狮头 --loop
一起做动作.cmd 舞狮头 --repeat 5 --interval 3000
一起做动作.cmd 吃 --loop --random
一起做动作.cmd 舞狮头 --only main,claude1
```

选项：`--loop` 一直转、`--repeat N` 转 N 轮、`--interval 毫秒` 间隔、
`--random` 每轮随机换一个、`--only 实例1,实例2` 只发给其中几只、
`--facing left|right` 镜像朝向、`--base http://127.0.0.1:端口` 手动指定端口。

> 端口探测失败时会提示；这时把 DSH 的地址手动传给 `--base` 就行。
> 实例 id 是配置里的 `pets[].id`（这台上是 `main` / `gemini1` / `gpt1` / `claude1`），
> 不是素材根名。

## 六、卸载

删掉 `<pet 目录>` 下的四样即可（都按名字前缀）：

```
gemini-config.json   gemini-animation\   gemini-avatar.webp   gemini-memes\
gpt-config.json      gpt-animation\      gpt-avatar.webp      gpt-memes\
claude-config.json   claude-animation\   claude-avatar.webp   claude-memes\
```

同步工具是绿色脚本，整个 `pet-sync\` 文件夹删掉就没了，不写注册表。

## 八、出问题先看这里

| 现象 | 原因 / 处理 |
|---|---|
| 「种类」里没有新角色 | 前缀没对齐（config / animation / avatar / memes 要同一前缀）；或者重启一次 DSH |
| 角色有了，碎碎念还是蓝毛小女仆 | `<名字>-memes\` 没拷过去，或者里面文件名被改了（必须跟梗名一模一样） |
| 碎碎念根本不发图 | 设置里 `whisperImageEnabled` 被关了 |
| 角色不说话/动作少 | 这批素材本身没有音频，只有动作 |
| `一起做动作.cmd` 说找不到端口 | DSH 没开，或端口探不到；用 `--base http://127.0.0.1:端口` 指定 |
| 双击后窗口一闪就没了 | 从 cmd 里跑一次看报错：`cmd /k 一起做动作.cmd` |
| 装了但动画方向反了/镜像怪 | 加 `--facing left` 或 `--facing right` 试试 |
| 想只留一只 | 卸载里删掉另外两只的四样文件 |
